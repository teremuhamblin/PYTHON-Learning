# CONTRIBUTING.md — Guide de contribution

Merci de votre intérêt pour le projet PYTHON-Learning.  
Ce projet est éducatif et vise à aider les débutants à apprendre le langage Python.

## 1. Principes généraux
- Le contenu doit rester simple, clair et pédagogique.
- Toute contribution doit respecter la licence éducative du projet.
- Les fichiers doivent être organisés proprement dans les dossiers existants.

## 2. Types de contributions acceptées
- Ajout de cours ou amélioration des cours existants.
- Création d'exercices supplémentaires pour les différents niveaux.
- Ajout de mini-projets pédagogiques.
- Corrections orthographiques, syntaxiques ou techniques.
- Amélioration de la structure ou de la documentation.

## 3. Structure du code et des fichiers
- Utiliser des noms de fichiers explicites.
- Respecter la structure des dossiers (`cours/`, `exercices/`, `projets/`, etc.).
- Les exemples Python doivent être courts et compréhensibles.

## 4. Processus de contribution
1. Fork du dépôt.
2. Création d'une branche dédiée à votre modification.
3. Ajout ou modification du contenu.
4. Mise à jour du CHANGELOG.md si nécessaire.
5. Création d'une Pull Request avec une description claire.

## 5. Style de rédaction
- Ton pédagogique.
- Explications simples.
- Pas de contenu commercial.
- Attribution obligatoire à Teremu pour tout contenu dérivé.

Merci de contribuer à rendre l’apprentissage de Python accessible à tous.
