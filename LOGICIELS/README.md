# Logiciels recommandés — PYTHON-Learning 🐍

Ce dossier contient la liste des logiciels recommandés pour utiliser et développer efficacement avec le projet PYTHON-Learning.

Les logiciels proposés sont adaptés aux débutants comme aux utilisateurs avancés, et couvrent les besoins essentiels : programmation, édition de code, gestion de versions, environnements virtuels et outils pédagogiques.

---

# 🧰 Logiciels recommandés

## 1. Python
Interpréteur du langage Python.
- Version recommandée : 3.10 ou supérieure
- Site officiel : https://www.python.org/

## 2. Visual Studio Code
Éditeur de code moderne, léger et extensible.
- Extensions recommandées :
  - Python
  - Pylance
  - Jupyter
- Site officiel : https://code.visualstudio.com/

## 3. Git
Gestion de versions indispensable pour suivre l’évolution du projet.
- Site officiel : https://git-scm.com/

## 4. GitHub Desktop
Interface graphique simple pour Git.
- Site officiel : https://desktop.github.com/

## 5. PyCharm Community (optionnel)
IDE Python complet pour les utilisateurs avancés.
- Site officiel : https://www.jetbrains.com/pycharm/

## 6. Jupyter Notebook (optionnel)
Outil interactif pour les démonstrations et cours avancés.
- Installation via pip : `pip install notebook`

## 7. FastAPI (optionnel)
Framework pour créer des API rapides et modernes.
- Installation via pip : `pip install fastapi uvicorn`
