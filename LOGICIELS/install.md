Installation des logiciels — PYTHON-Learning 🐍

Ce guide explique comment installer les logiciels nécessaires pour utiliser le projet PYTHON-Learning dans les meilleures conditions.

---

🧩 1. Installer Python

Télécharger Python :
https://www.python.org/downloads/

Cocher l’option :
`
Add Python to PATH
`

Vérifier l’installation :
`
python --version
`

---

🧩 2. Installer Visual Studio Code

Télécharger VS Code :
https://code.visualstudio.com/

Extensions recommandées :
- Python
- Pylance
- Jupyter

---

🧩 3. Installer Git

Télécharger Git :
https://git-scm.com/downloads

Vérifier l’installation :
`
git --version
`

---

🧩 4. Installer GitHub Desktop (optionnel)

Télécharger :
https://desktop.github.com/

Permet de gérer Git sans ligne de commande.

---

🧩 5. Installer PyCharm Community (optionnel)

Télécharger :
https://www.jetbrains.com/pycharm/download/

---

🧩 6. Installer Jupyter Notebook (optionnel)

Installer via pip :
`
pip install notebook
`

Lancer :
`
jupyter notebook
`

---

🧩 7. Installer FastAPI (optionnel)

Pour le projet 05 :
`
pip install fastapi uvicorn
`

Lancer une API :
`
uvicorn main:app --reload
`
