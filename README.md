# Apprentissage du langage Python 🐍

Bienvenue dans ce mini-projet pour apprendre Python facilement, même sans aucune connaissance en programmation.

## 🎯 Objectif
Apprendre les bases de Python à travers des petits fichiers simples et clairs.

## 📂 Structure
```text
PYTHON-Learning/
│
├── cours/
├── LICENSE
├── README.md
├── 01_hello_world.py
├── 02_variables.py
├── 03_conditions.py
├── 04_boucles.py
└── 05_fonctions.py
```

## 📂 Contenu
- `01_hello_world.py` → afficher un texte
- `02_variables.py` → créer et utiliser des variables
- `03_conditions.py` → comprendre les conditions (if / else)
- `04_boucles.py` → répéter des actions (for / while)
- `05_fonctions.py` → créer des fonctions simples

## ▶️ Comment exécuter
1. Installer Python (https://www.python.org)
2. Ouvrir un terminal
3. Lancer un fichier :
```python
01_hello-world.py
```

🚀 Bonne découverte !
