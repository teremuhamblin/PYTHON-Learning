### 🚀 Objectifs du projet

- Offrir un parcours complet pour apprendre Python du niveau débutant au niveau expert.  
- Proposer des exercices progressifs pour pratiquer.  
- Fournir des mini‑projets concrets pour appliquer les connaissances.  
- Mettre à disposition des ressources pédagogiques claires et accessibles.  
- Construire un écosystème éducatif structuré et évolutif.

---

### 🧭 Comment utiliser ce dépôt

1. Commencer par les cours débutants dans cours/.  
2. Pratiquer avec les exercices (à venir).  
3. Réaliser les mini‑projets pour consolider les acquis.  
4. Consulter les ressources pour approfondir.  
5. Suivre la roadmap pour connaître les futures évolutions.
