GLOSSAIRE.md — Glossaire Python et pédagogique

Ce glossaire regroupe les termes importants utilisés dans le projet PYTHON-Learning.

---

🐍 Termes Python

Variable
Zone mémoire contenant une valeur.

Fonction
Bloc de code réutilisable.

Boucle
Structure permettant de répéter des instructions.

Condition
Test logique permettant de prendre une décision.

Module
Fichier Python contenant du code réutilisable.

Classe
Modèle permettant de créer des objets.

Objet
Instance d’une classe.

Exception
Erreur gérée par Python.

JSON
Format de données structuré.

---

🎓 Termes pédagogiques

Cours
Document théorique expliquant un concept.

Exercice
Code à pratiquer pour renforcer un concept.

Projet
Application concrète d’un ensemble de concepts.

Ressource
Document complémentaire (image, fiche mémo, schéma).

Documentation
Informations techniques sur le projet.
