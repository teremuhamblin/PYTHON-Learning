METHODOLOGIE.md — Méthodologie de création des cours, exercices et projets

Ce document explique comment créer du contenu dans PYTHON-Learning de manière cohérente, pédagogique et structurée.

---

🎓 1. Création d’un cours

Format
- Fichier .md
- Sections claires
- Code Python en blocs
- Explications simples

Structure recommandée
`

Titre
Introduction
Concepts
Exemples
Exercices rapides
Conclusion
`

---

🧩 2. Création d’un exercice

Format
- Fichier .py
- Un seul objectif par exercice
- Pas de complexité inutile

Structure recommandée
`

Titre de l’exercice

Instructions

Code à compléter ou analyser
`

---

🚀 3. Création d’un projet

Format
- Dossier dédié
- README.md obligatoire
- Code structuré

Structure recommandée
`
projet_X/
│── README.md
│── main.py
│── modules/ (optionnel)
│── data/ (optionnel)
`

---

📘 4. Cohérence pédagogique

- Un cours introduit un concept  
- Un exercice le pratique  
- Un projet l’applique
