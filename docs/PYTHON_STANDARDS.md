🧱 PEP8 — Style Python

- Indentation : 4 espaces  
- Noms de variables : snake_case  
- Noms de classes : PascalCase  
- Noms de fonctions : snake_case  
- Longueur des lignes : 79 caractères max  
- Espaces autour des opérateurs : oui  
- Commentaires : clairs et utiles
