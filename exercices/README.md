# 📄 Dossier exercices/
### Exercices Python
- PYTHON-Learning 🐍

Ce dossier contient tous les exercices pratiques du projet PYTHON-Learning.  
Ils permettent d’appliquer les notions vues dans les cours et de progresser étape par étape.

Les exercices sont organisés par niveau : débutant, intermédiaire, avancé et expert.

---

📁 Structure des exercices

`
exercices/
│
├── debutant/
│   ├── 01helloworld.py
│   ├── 02_variables.py
│   ├── 03_conditions.py
│   ├── 04_boucles.py
│   └── 05_fonctions.py
│
├── intermediaire/
│
├── avance/
│
└── expert/
`

---

🎯 Objectif du dossier

Ce dossier a pour but de :

- proposer des exercices simples pour pratiquer Python ;
- accompagner les cours du dossier cours/ ;
- offrir une progression logique du niveau débutant au niveau expert ;
- permettre aux apprenants de tester leurs connaissances avec du code réel.

---

🧩 Contenu des niveaux

1. débutant/
Exercices très simples pour découvrir Python :

- afficher du texte ;
- manipuler des variables ;
- utiliser des conditions ;
- créer des boucles ;
- écrire des fonctions.

Les fichiers .py présents dans ce dossier sont directement liés aux cours de base.

---

2. intermediaire/
Exercices prévus pour :

- manipuler les listes et dictionnaires ;
- utiliser les exceptions ;
- lire et écrire des fichiers ;
- importer des modules.

(Contenu à venir selon la roadmap.)

---

3. avance/
Exercices prévus pour :

- POO avancée ;
- compréhension de listes ;
- fonctions lambda ;
- modules standards (os, json, etc.).

(Contenu à venir.)

---

4. expert/
Exercices prévus pour :

- design patterns ;
- programmation asynchrone ;
- optimisation ;
- tests unitaires ;
- architecture de projets.

(Contenu à venir.)

---

🚀 Comment utiliser les exercices

1. Choisir un niveau adapté à votre progression.  
2. Ouvrir un fichier .py.  
3. Lire l’énoncé (si présent) ou analyser le code.  
4. Exécuter le fichier :

`
python nomdufichier.py
`

5. Modifier le code pour tester vos idées.  
6. Revenir aux cours si nécessaire.
