# 📄 Dossier projets/
### Projets Python
### PYTHON-Learning 🐍

Ce dossier contient des mini‑projets Python conçus pour mettre en pratique les notions apprises dans les cours et les exercices.  
Chaque projet est simple, progressif et adapté à un apprentissage autonome.

Les projets sont organisés par difficulté croissante, du plus simple au plus structuré.

---

📁 Structure des projets

```text
projets/
│
├── projet01-calculatrice/
├── projet02-contacts/
├── projet03-jeudevinenombre/
├── projet04-analyse_fichiers/
└── projet05-api_fastapi/
```

---

🎯 Objectif du dossier

Ce dossier a pour but de :

- proposer des projets concrets pour pratiquer Python ;
- renforcer la logique de programmation ;
- apprendre à structurer un programme ;
- préparer l’apprenant à des projets plus avancés ;
- compléter les cours du dossier cours/ et les exercices du dossier exercices/.

---

🧩 Description des projets

1. projet01calculatrice/
Créer une calculatrice simple en Python :
- addition, soustraction, multiplication, division ;
- gestion des erreurs simples ;
- interaction avec l’utilisateur.

---

2. projet02contacts/
Créer un gestionnaire de contacts :
- ajouter un contact ;
- afficher les contacts ;
- sauvegarder dans un fichier texte.

---

3. projet03jeudevinenombre/
Créer un mini‑jeu :
- générer un nombre aléatoire ;
- demander à l’utilisateur de deviner ;
- donner des indices (plus grand / plus petit).

---

4. projet04analyse_fichiers/
Analyser un fichier texte :
- lire un fichier ;
- compter les mots ;
- afficher les statistiques.

---

5. projet05api_fastapi/
Créer une mini‑API :
- découvrir FastAPI ;
- créer une route simple ;
- renvoyer des données JSON.

---

🚀 Comment utiliser les projets

1. Choisir un projet dans le dossier.  
2. Lire le fichier README du projet (si présent).  
3. Exécuter le fichier principal .py.  
4. Modifier le code pour tester vos idées.  
5. Revenir aux cours si nécessaire.
