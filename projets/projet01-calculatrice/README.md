Projet 01 — Calculatrice Python 🧮

Ce projet est une calculatrice en ligne de commande écrite en Python.  
Elle permet d’effectuer des opérations simples : addition, soustraction, multiplication, division.

---

🎯 Objectifs pédagogiques

- Manipuler les variables
- Utiliser les fonctions
- Gérer les entrées utilisateur
- Gérer les erreurs simples (division par zéro, entrée invalide)

---

🚀 Utilisation

Depuis le dossier projet01-calculatrice/ :

`bash
python main.py
`

Puis suivre les instructions affichées à l’écran.

---

🧩 Fonctionnalités

- Choix de l’opération (+, -, *, /)
- Saisie de deux nombres
- Affichage du résultat
- Gestion de la division par zéro
- Boucle pour continuer ou quitter
