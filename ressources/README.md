# 📄 Dossier ressources/
### Ressources — PYTHON-Learning 🐍

Le dossier ressources/ contient tous les éléments complémentaires destinés à enrichir l’apprentissage du langage Python.  
Ces ressources ne sont pas des cours, mais des supports visuels, documentaires ou pratiques qui accompagnent les apprenants dans leur progression.

---

📁 Structure du dossier

```text
ressources/
│
├── images/
├── sources/
├── docs/
└── cheatsheets/
```

---

🖼️ images/
Ce dossier contient des éléments visuels utiles pour l’apprentissage :

- schémas explicatifs ;
- diagrammes ;
- illustrations pédagogiques ;
- images utilisées dans les cours ou projets.

---

📚 docs/
Ce dossier regroupe des documents pédagogiques :

- fiches de révision ;
- documents explicatifs ;
- guides thématiques ;
- supports PDF (si ajoutés ultérieurement).

---

🔍 sources/
Ce dossier contient :

- références externes ;
- liens ou fichiers de documentation ;
- ressources techniques utilisées pour créer les cours ;
- matériaux pédagogiques complémentaires.

---

🧾 cheatsheets/
Ce dossier contient des fiches mémo rapides :

- syntaxe Python ;
- structures de contrôle ;
- fonctions utiles ;
- modules standards ;
- bonnes pratiques.

Les cheatsheets sont conçues pour être consultées rapidement pendant l’apprentissage ou la réalisation des exercices.

---

🎯 Objectif du dossier ressources/
Ce dossier a pour but de :

- fournir un appui visuel et documentaire ;
- compléter les cours du dossier cours/ ;
- aider les apprenants à mémoriser plus facilement ;
- offrir des supports rapides pour réviser ;
- accompagner les exercices et mini‑projets.
